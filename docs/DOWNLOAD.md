## One app. Your next Home.

**[Download Quest Home Switcher v2](https://github.com/nikitat21/Quest-Home-Switcher/releases/download/v2/Quest-Home-Switcher-v2.apk)**

The same signed APK supports **Root and NoRoot**. Complete setup, then choose individual Homes inside the app. Both Libraries work without a GitHub sign-in.

> [!IMPORTANT]
> **Installing from a PC? Include `-g`.**
>
> `adb install -g Quest-Home-Switcher-v2.apk`
>
> [PC installation →](INSTALLATION.md#install-from-a-pc-recommended) · [Directly on Quest →](INSTALLATION.md#install-directly-on-quest)

Already using a v2 RC? Use **Check Update**, or manually install over it with `adb install -r -g`. Do not uninstall first. [Migration guide](MIGRATING-TO-V2.md)
