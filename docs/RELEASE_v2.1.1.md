# v2.1.1 · Home switching fix

[← Overview](../README.md) · [Download v2.1.1](DOWNLOAD.md) · [Installation](INSTALLATION.md)

- Fixed a version conflict that could stop **Apply Home** in NoRoot mode.
- Added a guarded replacement with a verified backup and safer rollback.
- Covers Official and Community Homes, including older packages such as City 17 and Minecraft Backrooms. Root switching is unchanged.

**Already on v2?** Use **Check Update** in the app. No uninstall is needed; keep your existing app and Home folders.

**New installation from a PC:** `adb install -g Quest-Home-Switcher-v2.1.1.apk`

Same app, same Libraries. [Explore the full v2 features →](RELEASE_v2.md)
